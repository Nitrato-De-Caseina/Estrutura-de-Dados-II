
# Projeto ConectaUDF – Redes Sociais com Grafos

## Sobre o projeto

O ConectaUDF é um projeto acadêmico desenvolvido com o objetivo de entender, na prática, como os grafos podem ser utilizados para representar as conexões entre pessoas em uma rede social.

Durante o trabalho, criamos uma rede fictícia de amizades, analisamos suas conexões e utilizamos Python para realizar cálculos relacionados aos usuários, como quantidade de amigos, grau dos vértices, número de arestas e densidade do grafo.

Também ampliamos a rede inicial, adicionando novos usuários e amizades, para observar como as conexões influenciam a estrutura de uma rede social.

## Objetivos

- Compreender os conceitos básicos de grafos e suas aplicações.
- Representar uma rede social utilizando vértices e arestas.
- Identificar a quantidade de conexões de cada usuário.
- Calcular o número de amizades e a densidade da rede.
- Utilizar Python para representar e analisar os dados.
- Entender como os amigos em comum podem ser utilizados para recomendar novas amizades.
- Refletir sobre a importância da privacidade e da proteção dos dados dos usuários.

## Conclusão

Com o desenvolvimento do projeto, conseguimos compreender melhor como os grafos funcionam e como podem ser aplicados em situações do cotidiano, principalmente nas redes sociais.
